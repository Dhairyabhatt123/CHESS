# ♟️ Real-Time Chess Game

A real-time multiplayer Chess game built using **chess.js** for game logic and **socket.io** for live, bidirectional communication between players. This project demonstrates real-time gameplay, multiplayer room management, and rule enforcement in classic chess.

## 🚀 Features

- 🔄 Real-time two-player gameplay using **Socket.IO**
- ♟️ Chess logic and move validation powered by **chess.js**
- 🔒 Unique game rooms for private matches
- ❌ Illegal move prevention
- 🎯 Turn-based move system
- 🕹️ Live board updates synced across clients
- ✅ Game end detection (checkmate, draw, stalemate)

## 🧰 Tech Stack

- **Frontend**: HTML, CSS, JavaScript (with chessboard UI library if used)
- **Backend**: Node.js, Express.js
- **Real-Time**: Socket.IO
- **Game Logic**: chess.js
